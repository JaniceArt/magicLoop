# Elixir Shop

A casual mobile puzzle game built with Unity where you manage a magical potion shop!

## Gameplay

- Ingredients automatically move along conveyor belts
- Tap ingredients to launch them into the matching cauldron
- Each cauldron brews a specific potion for waiting customers
- Complete all orders before the conveyor fills up to win!

## Features

- 30 handcrafted levels with increasing difficulty
- Multiple ingredient types and potion recipes
- Booster system: Shuffle and Magnet power-ups
- Hint system to guide new players
- Coin and heart economy
- Animated customers and cauldrons
- Original soundtrack and sound effects

## Built With

- Unity 6 (LTS)
- C#
- Unity Input System
- TextMesh Pro

## Platform

- Android (APK)
- WebGL (playable on itch.io)
